## Rev.0 Compatibility Analysis

### Sheet selection risk (HIGH)

`_prefer_micro_sheet()` priority order:
1. `microplanejamento_abril_junho` → NO MATCH (old monolithic sheet gone)
2. `microplanejamento` → **MATCHES V1 and V2** (both contain substring)
3. `inovesa`/`consolidado` → no match in sheet names
4. Fallback: first tab

ATM picks the **first** matching sheet in tab order. If V1 is before V2,
it works. If V2 is first, ATM loads the Nucleação variant (0.5 intensity)
instead of Plantio Total — **wrong results silently**.

**Mitigation needed**: Add `_V1` preference or explicit sheet name to priority list.
